# Security Policy

CalmLinks is a static HTML, CSS, and JavaScript template. It does not collect, store, or transmit user data by default.

Please report potential security issues privately to `security@example.com` rather than opening a public issue. Replace this placeholder email with the project maintainer's security contact before publishing.

Users are responsible for reviewing the security, privacy, and licensing of any third-party code, services, analytics, forms, embeds, or dependencies they add to CalmLinks.
